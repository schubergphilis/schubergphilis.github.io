# schubergphilis.github.io
The landing site, this is a Jekyll generated static site with a template
taken from <a href="html5up.net">html5up.net</a>. The template is integrated
with the site.
This site serves as a first index to our open source work. It is automatically
generated by github.

At this moment we have 5 categories:
* Chef
* Infrastructure as code (with references to cosmic, chef and K8S)
* Operations
* powershell
* security

To add your project, add a reference to the cookbooks or the projects folder.
New categories require an entry in the categories folder and the menu file.

## How to run this locally?
Make sure you have Jekyll installed. For that you need to install gpg and rvm.
Simple instructions are:
```
$ brew install gpp
$ command curl -sSL https://rvm.io/mpapis.asc | gpg --import -
$ \curl -L https://get.rvm.io | bash -s stable
$ rm $HOME/.profile # be aware that rvm is quite aggressively installing itself
$ source "$HOME/.rvm/scripts/rvm"
$ rvm install ruby-2.4.1
$ rvm gemset use global
$ gem install jekyll bundler  # the stuff
```

If you have everything setup, there are two magic commands
```
$  bundle exec jekyll serve --incremental   # run a local server
```
and
```
$ bundle exec jekyll build # rebuild the whole site
```
